# Простая лендинговая страница

Представлена учебная лендинговая страница, реализованная на HTML, CSS, JavaScript.

**Иконки** с использованием ресурсов open source библиотеки *Font Awesome*.

**Анимация** с использованием ресурсов open source библиотеки *Animate.css* и JavaScript-анимация.

Дизайн страницы является минималистичным, с использованием нейтральных цветов и простых шрифтов.
